OllamaClient

class OllamaClient(configProvider: suspend () -> OllamaClientConfig, engine: HttpClientEngine? = null) : Closeable

Kotlin client for the Ollama REST API.

Supports both suspend (one-shot) and Flow-based (streaming) interaction.

val client = OllamaClient()
val response = client.chat(ChatRequest(model = "llama3", messages = listOf(...)))
client.close()
